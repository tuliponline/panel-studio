# Panel Studio

ออกแบบตู้ไฟ (electrical cabinet / panel layout) ภาษาไทย — เว็บสแตติกใน `dist/`

## คุณสมบัติ

- กำหนดขนาดตู้จริง (กว้าง/สูง/ลึก มม.) และเลือก preset มาตรฐาน
- จัดวางอุปกรณ์มาตราส่วน DIN (~18 มม./โมดูล) พร้อมราง DIN และรางสาย
- **ลากวางเต็มรูปแบบ**: ลากจากแคตตาล็อกลงราง (ghost + snap 18 มม. + ไฮไลต์ราง / แดงถ้าไม่พอ) · ลากย้ายอุปกรณ์/ราง · ลากลงถังเพื่อลบ · Undo/Redo (Ctrl+Z/Y)
- **เดินสายด้วยการลาก**: กดขั้วแล้วลากไปขั้วปลายทาง · เส้นตัวอย่างสด · มุมเลี้ยวปรับได้ · สีสายด่วน (L/N/PE)
- Pan/zoom: ล้อเมาส์ / pinch · ลากพื้นว่างเลื่อนมุมมอง · ปุ่มพอดีจอ
- แคตตาล็อกอุปกรณ์ขยายได้ใน `dist/catalog.js` (GLINK, Nano Plus, DZ47-63, TS35, MCB, RCBO ฯลฯ)
- เตือนเมื่ออุปกรณ์ไม่พอดีราง / ลึกเกินตู้ / นอกแผ่นติดตั้ง
- Responsive: มือถือเป็น bottom sheet (กดค้างเพื่อลาก · แตะสั้นเพื่อเพิ่ม) · แท็บเล็ต · เดสก์ท็อป
- บันทึกอัตโนมัติในเบราว์เซอร์ · นำเข้า/ส่งออก JSON · ส่งออก SVG · โหลดโปรเจกต์เก่าได้

## รันท้องถิ่น

```bash
npx --yes serve dist
# หรือ
python3 -m http.server --directory dist
```

เปิดเบราว์เซอร์ที่พอร์ตที่แสดง แล้วใช้งานได้ทันที (ไม่ต้อง build)

## Deploy (Vercel)

Output directory: `dist` — push ไปที่ `main` แล้ว auto-deploy

## ขยายแคตตาล็อก

แก้ `dist/catalog.js` เพิ่มอ็อบเจ็กต์ใน `devices[]`:

| ฟิลด์ | ความหมาย |
|------|-----------|
| `id` | รหัสในไฟล์บันทึก |
| `name` / `nameTh` | ชื่อสั้น / ชื่อไทย |
| `modes` | `['AC']`, `['DC']` หรือทั้งสอง |
| `modules` | ความกว้างเป็นโมดูล DIN (×18 มม.) |
| `poles` | จำนวนขั้วต่อสาย |
| `heightMm` / `depthMm` | ขนาดโดยประมาณ |
| `freePlace` | วางอิสระ (หน้าตู้) ไม่ snap ราง DIN |
| `isTerminalBar` | บาร์ N/PE ติดแผ่น (นอก DIN) · ปรับจำนวนจุด/ความยาว/แนว/บทบาทได้ |

หมวด **Busbar / บาร์กราวด์-นิวตรอล** (ติดแผ่น · กริด 2.5 มม. · ไม่ขึ้น DIN):
- บาร์ทองเหลือง N/PE — หน้าตัด 6×9 / 8×12 · ฐานมาตรฐาน/ปีก · ขาน้ำเงิน/เขียว
- บาร์กราวด์ I-din — แผ่นนิเกิลงอปีก · สกรูใหญ่ปลาย + เล็กกลาง
- บาร์ทองแดง 110A — ฉนวนแดงทรงกระบอก · สลักหกเหลี่ยม
